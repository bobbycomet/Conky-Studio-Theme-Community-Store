# Conky-Studio-Theme-Community-Store
This is the official Community store for themes. Read the [Themes Schema](https://github.com/bobbycomet/Conky-Studio-Theme-Community-Store/blob/main/THEME_SCHEMA.md) for how to add your theme to the store.


If you are hosting it on OpenDesktop/Pling, OCS is used to download it.
If you are using GitHub to host it, make sure you have the zip/tar file in releases. Otherwise, it will not install.
